Kebijakan Privasi HSK Reader DuDu

Pengelola: Grow & Grow & Grow Pty Ltd (ACN 635 108 299)

Tanggal berlaku: 22 September 2026

Aplikasi: HSK Reader DuDu (com.sim.chinesereader) — di perangkat ditampilkan sebagai Sightreader (iOS dan Android)

English: Privacy policy (EN)

Ringkasan

HSK Reader DuDu membantu Anda berlatih membaca bahasa Mandarin. Tidak ada akun pengguna dan tidak ada pelacak iklan. Data belajar tersimpan di perangkat Anda. Saat Anda membuat cerita, kalimat latihan, terjemahan, atau tip menghafal, permintaan tersebut dikirim melalui server kami ke penyedia AI agar fitur dapat berjalan.

Data yang kami proses

Disimpan di perangkat Anda

  • Artikel tersimpan, kartu flash, progres membaca, dan pengaturan
  • ID instalasi anonim (pengenal acak perangkat/aplikasi) untuk membatasi kuota pembuatan konten harian gratis

Menghapus data aplikasi atau menginstal ulang akan menghapus data lokal dan dapat mereset kuota harian.

Dikirim ke server kami (dan penyedia AI) saat Anda memakai fitur generate

  • Pengaturan cerita (genre, tingkat, panjang, kosakata)
  • Konten yang Anda buat/kirim untuk diproses: prompt khusus, teks artikel yang ditempel, atau URL yang Anda pilih
  • Kalimat yang diminta untuk diterjemahkan dan kata untuk tip menghafal
  • ID instalasi anonim untuk kuota harian (dan, jika ID tidak ada atau tidak valid, alamat IP hanya sebagai kunci kuota cadangan — bukan untuk menentukan kota atau lokasi akurat Anda)

Kami menggunakan penyedia AI seperti DeepSeek dan, jika dikonfigurasi, Google Gemini. Konten yang Anda kirim dapat diproses di luar Indonesia.

Log operasional (diminimalkan)

  • Metadata pembuatan konten (metode, genre, sukses/gagal, penyedia)
  • Penghitung kuota harian berdasarkan ID instalasi (atau IP cadangan)
  • Kami tidak menyimpan teks lengkap prompt khusus Anda di log analitik

Keamanan

  • Komunikasi antara aplikasi dan server kami menggunakan HTTPS (dienkripsi saat transit)
  • Aplikasi tidak memakai SDK iklan atau SDK pelaporan crash terpisah

Yang tidak kami lakukan

  • Tidak ada registrasi atau login akun (tidak mengumpulkan ID pengguna akun, nama, atau email lewat aplikasi)
  • Tidak menjual data pribadi
  • Tidak memakai SDK iklan pihak ketiga atau mengumpulkan ID iklan untuk iklan
  • Tidak mengakses GPS / lokasi perangkat; kami tidak memakai layanan lokasi atau memetakan IP ke lokasi perkiraan untuk fitur aplikasi
  • Tidak melakukan pelacakan lintas aplikasi

Retensi

  • Data perangkat: sampai Anda menghapusnya atau menghapus aplikasi
  • Penghitung kuota: sekitar 14 hari lalu dibersihkan
  • Metadata pembuatan: sekitar 30 hari lalu dibersihkan
  • Konten yang dikirim ke penyedia AI diproses untuk memenuhi permintaan Anda; kami tidak menyimpan perpustakaan permanen cerita yang Anda hasilkan di server kami

Pilihan Anda dan penghapusan data

  • Jangan gunakan fitur generate jika Anda tidak ingin konten dikirim ke penyedia AI
  • Hapus data di perangkat: hapus penyimpanan aplikasi / instal ulang untuk menghapus data belajar lokal dan mereset ID instalasi
  • Minta penghapusan catatan operasional: email support@growgrowgrowapps.com dengan subjek Sightreader — permintaan penghapusan data. Jelaskan apa yang ingin dihapus (misalnya log operasional terkait pertanyaan dukungan). Kami akan merespons dalam waktu wajar dan menghapus atau menganonimkan catatan yang dapat kami identifikasi.

Hak data pribadi (UU PDP Indonesia)

Jika Anda berada di Indonesia, Anda dapat meminta informasi pemrosesan terkait pertanyaan dukungan yang Anda kirim, meminta koreksi, atau meminta penghapusan catatan operasional terkait pertanyaan tersebut bila berlaku. Email: support@growgrowgrowapps.com.

Anak-anak

HSK Reader DuDu ditujukan untuk pelajar bahasa Mandarin secara umum, bukan khusus anak di bawah 13 tahun.
