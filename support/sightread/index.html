Before you write

1. Confirm you have an internet connection for generation features

2. Try again after waiting if you hit a daily limit (“come back tomorrow”)

3. Note whether the issue happens on generate, translate, flashcards, or cloze

4. Include your app version if you know it (Settings → About / App Store listing)

Report inappropriate content

Email support@growgrowgrowapps.com with subject Sightread — content report, or use Settings → Report content in the app. Include a short description and, if possible, a snippet of the problematic text.
